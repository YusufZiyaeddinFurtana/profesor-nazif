# Dil desteği

Türkçe (`tr`, varsayılan), İngilizce (`en`), basitleştirilmiş Çince (`zh-Hans`) ve Hiligaynon (`hil`) desteklenir. Navbar'daki yerel select dil değiştirir; mevcut kategori, ders ve tema korunur. Tercih `nazif-language-v1` anahtarında saklanır. Depolama kapalıysa dil seçimi açık oturum boyunca çalışır.

## Metinleri düzenlemek

- `src/i18n/locales/`: arayüz metinleri. Türkçe dosyası anahtar tiplerini belirler; diğer dillerde eksik anahtar build sırasında hata verir.
- `src/i18n/content/categories.ts`: kategori ve ana sayfa alanlarının çevrilmiş başlıkları/açıklamaları.
- `src/i18n/content/mockLessons.ts`: yalnızca örnek derslerin çevirileri.
- `src/i18n/LocaleProvider.tsx`: ortak dil state'i, kalıcılık, HTML `lang` ve sayfa açıklaması.
- `src/i18n/i18n.css`: dil seçici ve metin uzunluğu/Çince tipografi uyarlamaları.

Yeni bileşende `useLocale()` içindeki `t("anahtar", {parametre: değer})` fonksiyonunu kullanın. Cümleleri parçalardan birleştirmek yerine bütün çeviriyi bir anahtarda tutun. Sayılar gerektiğinde `Intl.NumberFormat(locale)` ile biçimlendirilebilir.

## Backend dersleri

`Lesson.translations` isteğe bağlıdır; her dil girdisi `title`, `summary`, `longDescription` alanlarını birlikte taşır. Örneğin:

```json
{
  "translations": {
    "en": {
      "title": "Your first robot code",
      "summary": "Explore your FRC project.",
      "longDescription": "Learn how commands reach the robot."
    }
  }
}
```

`parseLessons` bu alanları doğrular. `localizeLesson` yalnızca görünen üç metni değiştirir; `id`, `program`, `group`, `topic` ve adresler sabittir. İstenen dilin çevirisi yoksa API'nin özgün metni gösterilir. Örnek dersin kimliğiyle aynı kimlikte bir API dersi gelse bile yerel örnek çevirileri API içeriğinin üzerine yazılmaz.

Kategori eklerken çeviri kayıtlarını da ekleyin. Görünen başlık değişse bile `slug`, `group` ve `topic` eşleme anahtarlarını çevirmeyin.

## Çeviri kontrolü

Hiligaynon metinleri ilk çeviri taslağıdır; yayına yönelik dil kontrolü için ana dili konuşan bir ekip üyesinin gözden geçirmesi önerilir. Robotik terimleri ve FIRST/FRC/FLL adları gerektiğinde özgün biçimleriyle korunmuştur.
