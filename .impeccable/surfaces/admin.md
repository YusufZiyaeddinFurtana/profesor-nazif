# Content administration — /admin
Mode: Operate.
Task: a trusted educator adds a lesson, attaches a YouTube reference and private PDF, then saves a draft or publishes.
Inherit paper/deep green tokens and DM Sans from the established site. Calm two-column library/editor; stacked on mobile. Native labeled fields, grouped media controls, inline validation and persistent save feedback. No decorative motion, charts or new branding. Both themes and the existing four languages apply.
Authorization comes from a server-controlled admin role, with database enforcement on each write; never from user-editable metadata. Access errors and loading states must fail closed.
